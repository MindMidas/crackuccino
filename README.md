# **Overview**

Crackuccino is a substitution-cipher project written in **C**. It can encrypt plaintext, decrypt with a known letter mapping, or brute-force ciphertext by checking candidate plaintext against a dictionary.

The project builds four executables:

- `encrypt`
- `decrypt-key`
- `decrypt-serial`
- `decrypt-mpi`

The MPI program splits permutation work across ranks. Dictionary files are plain text files with one word per line.

The project report is here: [report.pdf](report.pdf).

---

# **Pre-Requisites**

Ensure these are installed:

- GCC or Clang
- GNU Make
- Open MPI (`mpicc` and `mpirun`)
- Python 3, only needed for the test runner

# **How to Build & Run**

## 1. Build

```bash
make
```

This creates:

- `encrypt`
- `decrypt-key`
- `decrypt-serial`
- `decrypt-mpi`

To remove generated binaries and `ciphertext.txt`:

```bash
make clean
```

The helper script wraps the common commands:

```bash
./build build
./build test
./build full-test
./build clean
```

## 2. Encrypt Text

```bash
./encrypt "hello world" --key helowrd
```

Output:

```text
input_dict: helowrd
encrypt_dict: helowrd
ciphertext: hello world
wrote: ./ciphertext.txt
```

Without `--key`, the program shuffles the detected plaintext letters randomly.

## 3. Decrypt With a Known Key

```bash
./decrypt-key ciphertext.txt --input-dict helowrd --encrypt-dict helowrd
```

Output:

```text
ciphertext: hello world
input_dict: helowrd
encrypt_dict: helowrd
plaintext: hello world
```

## 4. Serial Brute Force

```bash
./decrypt-serial ciphertext.txt dictionaries/small_dictionary --stats
```

Example output:

```text
[rank 0] [permutation: helowrd] found: hello world
```

## 5. MPI Brute Force

```bash
mpirun -np 2 ./decrypt-mpi ciphertext.txt dictionaries/small_dictionary --stats
```

Example output:

```text
[rank 0] [permutation: helowrd] found: hello world
```

Use `--progress` to show the live MPI rank table. For append-only terminal logs, run progress mode like this:

```bash
CRACKUCCINO_PROGRESS_PLAIN=1 mpirun -np 2 ./decrypt-mpi ciphertext.txt dictionaries/small_dictionary --stats --progress
```

# **Testing**

Run the smoke test:

```bash
./build test
```

Run the full Python test suite:

```bash
./build full-test
```

`./build test` compiles the project, checks the direct and serial paths, and runs a small MPI test when `mpirun` is available.

---

# **Notes**

- `ciphertext.txt` is generated by `encrypt`.
- Custom dictionaries should contain one word per line.
- `decrypt-key` does not brute force; it uses the provided mapping directly.
- `decrypt-serial` and `decrypt-mpi` can become expensive when the ciphertext has many unique letters.
